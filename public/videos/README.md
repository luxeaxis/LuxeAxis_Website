# Luxe Axis Hero Video Assets

Place your 1080p architectural project video loops (H.264 MP4, muted, 24/30fps, 10–15s duration) in this directory:

- `hero-slide-1.mp4`: Poes Garden Architectural Residence showcase
- `hero-slide-2.mp4`: Adyar Waterfront Penthouse showcase
- `hero-slide-3.mp4`: OMR Innovation Campus showcase
- `hero-slide-4.mp4`: ECR Beachfront Sanctuary showcase

If an `.mp4` file is omitted or fails to load, the hero video slider automatically falls back to high-resolution poster images in `/public/posters/`.
